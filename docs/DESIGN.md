# Design and editorial notes
- Look: cold grey landscape; Instrument Serif headings (Vazirmatn bold in Persian), IBM Plex Sans/Mono; accent = pale frost blue, copper as the contrast hue.
- Copy rules: describe patterns between countries, never causes; state weak results as weak (month effect weak/unstable; winter idea not supported;
  Friday effect strong). Every chart has a one-line reading next to it. Limits live on `/method`.
- Safety: help-line note on the home page (findahelpline.com); no glorifying language; band pages show facts only.
- Images: link out, show initials when a logo fails; never copy files.
